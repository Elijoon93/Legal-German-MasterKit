# Legal German MasterKit

وب‌اپ استاتیک و آفلاین برای آمادگی زبان آلمانی حقوقی در مسیر:

**LL.M. oec. Privates und Öffentliches Wirtschaftsrecht — Friedrich-Schiller-Universität Jena**

## اجرای محلی

فایل `index.html` را مستقیماً در مرورگر باز کنید؛ یا در پوشه پروژه اجرا کنید:

```bash
python -m http.server 8000
```

سپس نشانی زیر را باز کنید:

```text
http://localhost:8000
```

## انتشار با GitHub Pages

1. محتوای این پوشه را در ریشه مخزن قرار دهید.
2. در GitHub وارد `Settings > Pages` شوید.
3. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.

## ساختار
